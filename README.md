## Structure

Each paper lives in its own folder, named `<year>-<semester>-<course>-<topic>`:

```
2026-ws-ki-grundlagen-<topic>/
├── README.md     # question, approach, key findings
├── paper.pdf     # the written paper
├── slides.pdf    # the presentation
└── src/          # optional: LaTeX, Markdown, notebooks, or slide sources
```

A blank template is in [`_template/`](_template/).
